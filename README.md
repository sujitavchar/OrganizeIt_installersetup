# 🗂️ OrganizeIt

A modern desktop app that tidies up your files with one click, now trusted by **1 000+ users worldwide**.  
OrganizeIt v2.0 introduces a sleek UI  rule‑based categorization, custom backgrounds, and a fully installable Windows package.

• Engineered a Python-based automation tool to categorize files by type, serving about 1k users with a 90%
satisfaction rate.
• Streamlined user workflows, saving an average of 40% in manual organization time through automatic and
customizable file handling.
• Managed the full software lifecycle from development (Python, Tkinter) to deployment using PyInstaller and Inno
Setup

---

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| **One‑click organization** | Instantly sort cluttered folders into neat, hierarchical structures. |
| **Rule‑based engine** | Define custom rules in plain text (e.g. `*.pdf => /Docs/`, `*.jpg => /Pictures/2025`) for surgical control. |
| **Live animated feedback** | See progress with smooth, unobtrusive animations. |
| **Themeable UI** | Choose background images or solid colors to suit your mood. |
| **Portable & installer builds** | Distributed as a standalone EXE (PyInstaller + Inno Setup); no Python required on user machines. |
| **Safe‑move algorithm** | Never overwrites existing files—conflicts are auto‑renamed with timestamp suffixes. |
